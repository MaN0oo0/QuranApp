<h2>Overview</h2>
<p>QuranApp is a modern web platform designed for immersive Quranic exploration, combining performance, interactivity, and maintainability. Built with a modular architecture, it offers seamless navigation, dynamic content rendering, and multimedia support to enhance the user experience.</p>
<p><strong>Why QuranApp?</strong></p>
<p>This project aims to provide a reliable, scalable, and engaging environment for exploring Quranic content. The core features include:</p>
<ul class="list-disc pl-4 my-0">
<li class="my-0">🎯 <strong>🚀 Fast Development:</strong> Utilizes Vite for rapid build times and a smooth local development experience.</li>
<li class="my-0">🌐 <strong>🧭 Client-side Routing:</strong> Ensures seamless navigation between pages like Surah, Juz, and Ayah without page reloads.</li>
<li class="my-0">🖥️ <strong>📝 Dynamic Templates:</strong> Uses Handlebars to render content dynamically, supporting detailed Surah views and error pages.</li>
<li class="my-0">🎶 <strong>🎧 Audio Integration:</strong> Enables users to listen to Quranic verses directly within the app.</li>
<li class="my-0">🔧 <strong>🔗 Modular Architecture:</strong> Organized URL paths, services, and components for easy maintenance and scalability.</li>
<li class="my-0">🤖 <strong>🤝 Automated Workflows:</strong> CI/CD pipelines ensure reliable testing and publishing of updates.</li>
</ul>
